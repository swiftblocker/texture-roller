## Key claims
- Default pattern (relief) depth: 2 mm; README says 1.5 to 3 mm reads clearly.
- Roller settings: diameter, length, plain end bands, bore options (solid, 8 mm rod, 1/2 in or 3/4 in dowel, custom).
- Example roller in hero image: 40 x 150 mm.
- Printer limits (Bambu H2C): roller length up to 320 mm (325 mm right nozzle only); diameter up to 300 mm.
- Print settings: 0.16 mm layers (0.12 or 0.20 selectable), Arachne walls, 15% gyroid infill, outer brim on tall slim rollers.
- Relief modes: pressed in or raised; mirror on roller on by default.
- Release advice: PLA fine; PETG copes with warm water; dust with cornstarch or roll leather-hard clay.
- No CNC or cookie numbers. Minimum line width is a UI warning; value not stated.
