# Clay shrinkage (wet to fired)

Used by R27 (fired-size slab preview) and R28.
The engine's preset value is the middle of the range. The user can override it with the number from their clay's spec sheet.

| Body | Range | Preset | Sources | Note |
|---|---|---|---|---|
| Earthenware (cone 06-04) | 5-10% | 7% | S106, S107 | cone 04 bodies can be about 2% (S108) |
| Stoneware (cone 5-10) | 10-15% | 12.5% | S106, S107, S109 | Laguna cone 6: white 13%, red #80 14%, #90 13%, Redstone 10.5% (S105, retailer copy) |
| Porcelain (cone 6-10) | 14-17% | 15% | S107, S108 | softens most near maturity; detail rounds (S087) |
| Paper clay | 12-16% | 14% | S105 | |

No source gives drying (wet to bone-dry) shrinkage separately. Leather-hard is about 12-14% moisture, which is where wet-to-dry shrinkage stops (S106, weak).

Fired image height for a 254 mm wet image: earthenware 236 mm, stoneware 222 mm, porcelain 216 mm.
For a 254 mm FIRED stoneware image, the wet image would need 290 mm, which is over the R01 limit.
